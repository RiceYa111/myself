# Myself · 每一小步，都算数

成长型 AI 陪伴应用：陪伴引导式 Agent 把个人目标拆解为每天可执行的小任务，像素养成游戏为行动提供持续反馈。

**线上体验（推荐，国内访问快）：https://myself-9az.pages.dev**

备用地址：https://riceya111.github.io/myself/

手机浏览器打开体验最佳；电脑端会居中显示手机比例界面。首次加载约 1.1 MB 图片资源，之后有缓存秒开。

## 产品简介

Myself 面向「有目标、但在规划、启动或持续执行上遇到困难」的用户：

- **目标拆解**：与 Agent 对话澄清目标、基础、可用时间与现实阻碍，生成「最终目标 → 阶段成果 → 每日任务」的完整计划，经用户确认后生效
- **每日行动**：任务计时、完成结算经验与金币，奖励即时可见
- **动态调整**：生活节奏变化时可通过对话缩减、顺延或重新规划，中断后低负担回归，已有成果保留
- **连续陪伴**：Agent 记住用户确认过的偏好与经历，后续交流不再重复解释；记忆支持查看、更正与删除
- **游戏化成长**：像素小屋与角色随等级成长，金币可兑换任务卡与装扮，成长笔记沉淀阶段回顾

## 技术架构

```
浏览器端（Cloudflare Pages / GitHub Pages 静态前端，存档与记忆保存在本地 localStorage）
    │  HTTPS
    ▼
Cloudflare Worker（中继转发 · 密钥保管 · 限流 · 埋点收集）
    │                            │
    ▼                            ▼
DeepSeek API              Cloudflare KV
（deepseek-chat，          （限流计数 · 匿名统计）
 JSON 结构化输出）
```

- **密钥不出服务端**：DeepSeek API Key 存于 Cloudflare 保密变量，前端与仓库均不可见
- **成本护栏**：每 IP 每日 30 轮对话、全局每日 500 轮，超限返回友好提示；CORS 白名单限制调用来源
- **隐私口径**：埋点仅记录匿名计数（不含任何聊天内容）；用户数据默认保存在用户自己的设备上

## Agent 训练与评测

Agent 未做模型微调，通过「评测集驱动的提示词工程 + 服务端硬校验」达到上线标准：

- 自建 50+ 对话评测案例库，覆盖日常分享、情绪倾诉、计划制定、边界处理四类场景，历经 3 轮系统评测迭代
- 提示词层：人设规则（先接住情绪再推进话题、不臆断用户经历、每轮只问一件事）、业务规则（授权后才生成计划、记忆可删改）、防复读约束、服务端北京时间注入
- 服务端硬校验：承诺必兑现（说「记下了」必须真实写入记忆）、删除记忆先核对存在性、计划输出须通过结构校验，提示词管「说对话」、代码管「做对事」

## 数据埋点

首版埋点覆盖核心转化漏斗：打开应用 → 看到开场白 → 开始聊天 → 生成计划 → 确认创建目标 → 完成任务。匿名访客按日去重，区分新客与回头客；配套数据看板按天汇总近 7 天趋势，支撑次日迭代决策。

## 本地运行

```bash
node server.cjs   # 打开 http://localhost:4212
```

本地运行需要 Node.js，无须安装依赖；Agent 接口需配置本机模型密钥（`%LOCALAPPDATA%\Myself\model-config.json`），未配置时走云端中继。

## 目录结构

- `index.html` / `app.js` / `model.js`：页面组件、交互与业务规则
- `home.js` / `plans.js` / `growth-ui.js` / `wardrobe*.js`：房间、计划、成长记录、背包商城
- `deepseek-service.cjs` / `agent-rules.js` / `Agent人设.txt` / `Agent业务规则.txt`：Agent 服务与人设规则
- `analytics.js`：前端埋点采集
- `deploy/`：Cloudflare Worker 构建脚本与产物、数据看板
- `assets/`：像素风美术资源（WebP）

## 本版边界（MVP）

- 数据保存在浏览器 localStorage，清浏览器数据会丢失；跨设备同步与账号体系在后续版本评估
- 商城充值、复杂成就、成长图鉴为后续版本内容；当前金币与任务卡仅通过任务赚取
- 已知待优化：不同屏幕的自适应适配（当前为手机比例居中显示）
