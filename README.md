# Myself · P0交互原型

## 启动
在本目录运行 `node server.cjs`，浏览器打开 http://localhost:4173 。也可运行 `npm start`。需要Node.js，无须安装运行依赖。

本版是手机比例的浏览器交互原型，不是Android/iOS安装包。本地服务只监听当前电脑，未发布到互联网。

## 建议体验顺序
1. 首页点击“开始行动”，暂停、继续后点击“已完成”。金币从400变500，任务只结算一次。
2. 点击顶部任务卡“＋”，兑换一张卡；背包与首页同步更新。
3. 在计划中新建目标，填写基础、时间、困难，核对摘要和每日方案，再确认扣卡创建。
4. 展开目标，体验暂停、单项调整、取消和撤回。取消与撤回各每自然月2次，每个目标只能撤回一次。
5. Agent中输入“记住：我喜欢早晨阅读”；打开记忆、更正或删除，再询问偏好。
6. 点击设置，切换到无卡兜底场景，完成免费行动，再兑换任务卡。
7. 设置中可测试邮箱绑定/恢复演示、模拟离线，以及导出埋点JSON。

场景切换前保存上一次场景，可通过“恢复上一次场景”恢复。刷新会保留当前浏览器中的状态。

## 已实现
房间、计划四种状态、目标澄清与方案确认、单项任务开始/暂停/完成、基础成长记录、单项计划调整、取消撤回、金币与任务卡兑换/流水、日常交流演示、记忆查看/更正/删除、邮箱表单演示、免费基础行动、空状态及业务错误提示。

奖励、余额和目标状态由统一的规则模块处理。任务完成、兑换和创建具有原型内的重复提交防护。修改计划不改已结算记录与奖励预算。

## 本版边界
- **Agent为明确标注的本地规则演示**，不是已训练或已联网的大模型。澄清采用表单收集；每日计划提供可编辑模板；复杂目标、多目标冲突建议与真实语义判断尚未接入。
- **邮箱不发送邮件**。演示验证码是246810，仅用于展示流程；找回恢复的是此浏览器中绑定时保存的快照，不具备重装或跨设备找回能力。
- 数据位于浏览器localStorage，不是生产数据库。清除浏览器数据会丢失记录；多窗口同步不等于服务端并发安全。
- 起始金币400、任务卡2、经验300和阅读目标均为测试夹具。空白场景卡数3。显示累计经验，不擅自拟定完整升级曲线。
- 任务卡暂按本组效果图与既有F-09的500金币配置；如最终确定限购/1000金币档，应先统一规则再更新配置与验收。
- 不包含计时、新手完整流程、换装商城、复杂成就、真实充值或广告。不因效果图素材出现相关元素而扩大P0范围。
- 埋点仅本地记录可导出，未发送第三方。事件不包含聊天正文；本地聊天历史仍保存在当前浏览器。

## 验证

`browser-tests.cjs`：使用Playwright与本机Edge完成10组流程/布局检查；需环境提供Playwright。详见browser-test-results.json。测试使用独立浏览器上下文，不改变日常体验数据。

已验证360/390/430宽度不产生横向溢出。未宣称iPhone真机、原生系统后台行为或生产安全测试已完成。
