Myself 0.2 · DeepSeek 接入

启动：双击桌面 Myself 0.2 或本目录“启动原型.cmd”。
地址：http://127.0.0.1:4212
后端：api-server.cjs；密钥配置保存在当前 Windows 用户 LocalAppData/Myself/model-config.json，使用 Windows 账户加密。不要分享该配置。
模型配置：双击 configure-model.cmd；仅支持 DeepSeek 官方 HTTPS 接口。

真实能力：日常交流、结合最近对话/已保存偏好/活动目标澄清需求、阶段与每日任务草稿、单项计划调整建议。
执行边界：用户确认后才创建或调整；奖励由程序按评分转换，不接受模型任意指定金额。现有本地数据与原端口保留。
故障：连接失败显示明确错误及重试，不自动切回规则聊天。密钥只可在保存时的 Windows 账户下解密。

验证：真实分享对话、3日计划生成、扣卡与创建、单项调整均已通过。12项规则/输出校验测试通过。
当前仍是本地原型：业务数据保存在浏览器，不是云端账户服务；长期画像自动沉淀、生产级评测与服务监控尚未完整实现。
